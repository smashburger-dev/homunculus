# homunculus

The cortical homunculus is the map of the body inside the brain. This repo builds that map for one person: a swarm of always-on agents, each named after the anatomy that matches its job, that reads tracker data, subjective check-ins and new research, and keeps a training, nutrition and recovery plan up to date.
